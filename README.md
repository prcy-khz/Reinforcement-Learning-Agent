# Reinforcement Learning Agent

This project takes in input from a student which is their energy levels . This agent takes this information learns , and recommends the type of study plan that the student can implement.

## Features
- Reinforcement Learning
- Q-Table
- Epsilon-Greedy

## How to run
Steps to compile/run 
-Can Import it on the eclipse IDE
-Or command line javac Main.java, then java Main

## Usage
Example input/output or screenshots
Input: integers 1-4: these are the energy level from Exhausted to High
Input: rating of the suggestion from 1-5
Output: recommended study plan
